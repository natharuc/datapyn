## Contribuindo com a Documentacao

Ao adicionar nova documentacao:
1. Crie um arquivo `.md` descritivo neste diretorio
2. Adicione uma entrada neste README.md
3. Use formatacao Markdown clara e consistente
4. Inclua exemplos de codigo quando apropriado
5. Mantenha a documentacao atualizada com mudancas no codigo
