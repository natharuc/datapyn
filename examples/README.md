# Examples Directory

This directory contains example files demonstrating DataPyn features.

## Exported Analysis Example

`exported_analysis_example.py` - Example of a complete script exported from DataPyn showing:
- Database connection setup
- SQL blocks converted to `pd.read_sql()`
- Python code blocks
- Cross-syntax blocks with `{{ SQL }}` conversion
- Real-world e-commerce analysis scenario

This demonstrates the output of the "Export as Script" feature.
