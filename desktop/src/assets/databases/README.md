# Database marks

These local SVGs reuse the database logos in `source/src/assets/icons/db`, used by
the retained PyQt frontend. Original geometry and view boxes are preserved.
The `-dark.svg` copies change only the monochrome fill to `#dce7eb` for contrast
on dark surfaces. Databricks keeps its existing red mark in both themes.

MongoDB and Elasticsearch marks come from the CC0 Simple Icons collection
(`simple-icons/simple-icons`, `icons/mongodb.svg` and `icons/elasticsearch.svg`).
The Cosmos DB service mark is Microsoft's original
`10121-icon-service-Azure-Cosmos-DB.svg`, from the official Azure architecture
icons V25 archive at `https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V25.zip`.
Connection colors use the existing CSS mask; the source geometry stays intact.
